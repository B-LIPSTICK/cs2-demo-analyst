# CS2 Demo Analyst v1.0.1

本页资产已更新到 v1.0.1，之前下过旧包的请重新下载。

### 这一版改了什么

- 游戏内语音 HUD 只保留 Inject 一种方式。旧的 Addon 模式经实测在 CS2 引擎里不生效，设置页里那个选项已移除，不会再出现「选了却没反应」。
- 启动时会检查有没有新版本，有的话弹窗，并直接把这一版的更新说明显示在弹窗里。
- 弹窗里可以勾选「一天内不再提示」或「不再提示这个版本」。
- 设置页新增「更新」分组：可以关掉启动自动检查、手动检查一次、清除已跳过的版本。
- 版本号从这一版开始逐位递增（1.0.1 → 1.0.2 …）。

### 上一版已经带来的改动

删除录像时连带清掉该局的语音缓存（以前会攒到几十 GB）；玩家语音静音；VAC 纯净安全模式和一键还原；injector 不再改坏 gameinfo.gi 的换行；解析器修复选手遗漏与人机污染；界面整体换成 Quiet Blue；详情页改成回合同步的语音流；AI 接入硅基流动与智谱。

### 一个必须知道的前提

Valve 官方匹配下载的 demo 不带语音数据，本工具对它无法显示说话者 —— 数据不在文件里，任何工具都做不出来。带语音的是 FACEIT、5E、完美世界这类第三方平台的 demo。如果扫描后提示「无语音」，先确认 demo 来自哪个平台。

### 下载

- 下载 Assets 里的 `CS2-Demo-Analyst-1.0.1-win64-portable.zip`，解压到任意文件夹，双击 `CS2 Demo Analyst.exe`，不用安装。
- 升级就解压新包覆盖旧目录，配置和资料库在 `%APPDATA%\CS2 Demo Analyst`，不受影响。
- 请以本页 Assets 的 zip 为准。仓库 `dist/` 下的 `-setup.exe` 是 9 月 8 日的旧安装包，比 zip 老一个多月。
- 本地 Whisper 模型和 csgove 引擎在首次使用时按需下载，不在 zip 里。
