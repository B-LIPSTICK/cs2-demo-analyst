# CS2 Demo Analyst v1.0.0 正式版发布

**CS2 Demo Analyst** 是一款挂接 CS2 原生回放进程的电竞级录像分析工具：支持内置语音转写、游戏内开麦 HUD 悬浮层、交火提前量极速直跳、CS:GO 官方双轨胜负走势图，以及深度集成本地与国内主流大模型的一键 AI 智能战术复盘。

> **本页资产已于 2026-11-03 更新**：下方的便携包不再是 9 月初的构建，已同步到仓库 `frontend-apple` 分支最新代码（`b507aaf`）。此前下载过旧包的，请重新下载覆盖。

### 🆕 相对 9 月初构建的更新（2026-11-03）

- **删除录像时连带清理语音缓存**：整轨语音（一局约 300–500 MB）以前会永久堆在 `%APPDATA%` 里，实测可累积到 28 GB；现在删除条目、源文件消失、以及启动时清扫孤儿目录都会一并清掉。
- **玩家语音静音**：可单独或按阵营静音某位队员，HUD 上出现禁言徽标；静音状态通过 `tv_listen_voice_indices` 实时同步进 CS2。
- **VAC 纯净安全模式**：一键还原回放注入残留；默认走官方原生安全回放，根治 `steam_appid.txt` 引起的无签名报错。
- **播放稳定性**：修复打开 demo 后停留在主界面的问题，延长清理守护避免过早删除 cfg。
- **injector 换行修复**：注入 `SearchPath` 时保留原换行风格，`gameinfo.gi` 不再被永久改成 LF；Steam 自检也把换行状态纳入判定。
- **解析修复**：实体索引错位导致的选手遗漏与人机污染；适配 CS2 新版玩家名修饰后缀并清理 HTML 标签与转义符（解析器版本 9）。
- **界面重做**：Quiet Blue 苹果风设计、标题栏真应用图标、击杀流夜战重构、毛玻璃下拉、AI 页 2x2 布局。
- **详情页重构**：改为回合同步的语音流 + 精简控件；修掉两栏堆叠、击杀行被压扁、长 ID 穿模等问题。
- **AI 接入**：硅基流动 / 智谱直连，模型下拉可切换，回答里的回合与时间点可直接点跳。

### ✨ 核心特性

#### 1. 🎙 CS2 游戏内麦克风语音 HUD 悬浮层 (Panorama Overlay)
- **仿原生队员开麦指示**：
  - 游戏画面左下角实时呈现正在说话的队员；
  - 官方方形小圆角头像 + 阵营色名字（color-T / color-CT）+ 平滑呼吸光晕；
  - 基于 Valve 原生 Panorama 引擎与静态 VPK 压制，无外部进程注入；
  - 支持单人静音、按阵营批量静音，HUD 同步显示禁言状态。

#### 2. 🎮 CS:GO / CS2 原生双轨回合走势图 (Match Timeline Bar)
- **还原 CS:GO 记分板走势设计**：
  - 动态双轨分队（上下半区）与中场换边机制（T 琥珀金 / CT 冰霜蓝）；
  - 动态计算获胜方 5 格幸存人数槽（Survivor Bars），一眼看出残局 1vX 翻盘或完美歼灭；
  - 5 种矢量胜负图标：全歼敌方（Elimination）、雷包爆炸（Exploded）、成功拆包（Defused）、防守时间耗尽（Timeout）与终局奖杯（Trophy）；
  - 点击任意回合高亮选中，联动下方击杀流与高光事件。

#### 3. ⚡ 游戏内录像秒级直跳 (Live Jump with Lead-In)
- **4 秒交火提前量缓冲**：点击击杀流、战术事件或 AI 复盘时间戳，自动提前约 256 ticks（4 秒），完整观摩架枪、道具与对枪全过程；
- **智能双模响应**：
  - CS2 运行中：通过引擎底层下发 `demo_gototick` 实时秒切；
  - CS2 未启动时：一键自动拉起游戏并精准定位到目标 Tick 开始播放；
  - 选手数据弹窗内点击击杀跳转保持原有页面，不跳出、不打断复盘节奏。

#### 4. 🤖 AI 智能战术复盘与国内大模型接入
- **零门槛免梯直连**：原生深度集成国内主流免费与高性价比模型供应商（智谱 GLM-4-Flash、硅基流动 SiliconFlow、DeepSeek、Moonshot Kimi、Ollama 本地大模型）；
- **AI 时间戳可交互直跳**：复盘回答中所有的局数（如 `R2`）与时间点（如 `[02:15]`）均支持点击直接下发跳转；
- **中文转写约束与清洗**：集成 OpenCC 繁简转换与 Prompt 约束，确保中文语音转写纯正输出简体字。

#### 5. 🎨 极简苹果风设计系统 (Apple HUD Aesthetic)
- **原生深浅双主题**：纯白细腻日间模式与近黑毛玻璃夜间模式，支持一键无缝切换；
- **全矢量图标与实体交互**：全套细线 SVG 图标（雷达、拆包钳、刻度）与 Secondary 实体轻质卡片按钮。

#### 6. 🛠 深度解析与平台兼容
- **武器名称规范化**：自动清洗平台枪皮与特权标识（如 `hkp2000_txz04` → `P2000`），支持 Zeus、CZ75 及各类官方名刀；
- **真实对局时间提取**：自动从录像元数据与文件名时间戳中解析对局日期，告别下载时间干扰；
- **对战平台目录自动检测**：一键识别完美世界、5E、Steam 的录像目录。
