# CS2 Demo Analyst v1.0.2

本页资产已更新到 v1.0.2，之前下过旧包的请重新下载。

### 这一版改了什么

- 修复对战平台下载到一半的 zip 读不到的问题。5E 等平台的包有时中央目录没写完，以前整个包会被跳过、列表里显示 0 个；现在能把它里面的录像解出来正常入库。
- 资料库的目录列表每一行后面多了一个文件夹图标，点一下直接在资源管理器里打开该目录。
- 打开程序时，目录下拉默认回到「全部目录」；之前如果记住的目录已经不存在，会莫名其妙跳到完美平台那一项。选目录的对话框也会定位到上次用过的位置。

### 上一版的改动

游戏内语音 HUD 只保留 Inject 一种方式（旧的 Addon 模式经实测在引擎里不生效，选项已移除）；启动时检查新版本并弹窗显示更新说明，可勾选一天内或永久跳过；设置页新增「更新」分组；版本号逐位递增。

### 一个必须知道的前提

Valve 官方匹配下载的 demo 不带语音数据，本工具对它无法显示说话者 —— 数据不在文件里，任何工具都做不出来。带语音的是 FACEIT、5E、完美世界这类第三方平台的 demo。如果扫描后提示「无语音」，先确认 demo 来自哪个平台。

### 下载

- 下载 Assets 里的 `CS2-Demo-Analyst-1.0.2-win64-portable.zip`，解压到任意文件夹，双击 `CS2 Demo Analyst.exe`，不用安装。
- 升级就解压新包覆盖旧目录，配置和资料库在 `%APPDATA%\CS2 Demo Analyst`，不受影响。
- 请以本页 Assets 的 zip 为准。仓库 `dist/` 下的 `-setup.exe` 是 9 月 8 日的旧安装包，比 zip 老很多。
- 本地 Whisper 模型和 csgove 引擎在首次使用时按需下载，不在 zip 里。
