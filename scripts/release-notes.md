# CS2 Demo Analyst v1.0.7

本页资产已更新到 v1.0.7，之前下过旧包的请重新下载。已经在 1.0.6 上的可以直接点「一键更新」。

### 这一版改了什么

#### 下载不完整的 5E demo 卡在加载条（已修）

有些 5E demo 下载到一半就断了（客户端自己不再写盘，但文件并不完整），我们的解析器能读（容忍截断），所以选手数据、比分、回合数、时长全都正常显示，唯独点播放时 CS2 永远停在加载条上。

实测一份：zip 声明压缩数据 210,310,039 字节，实际只有 210,303,961 字节，少了 6,078 字节；解出的 dem 少 8,239 字节，尾部三块收尾数据（结束帧、spawn groups、fileinfo）整块丢失，头部记录的 fileinfo 偏移直接指到文件外。CS2 读完帧后按偏移找 fileinfo，找不到就卡住。

比赛数据本身没丢 —— 160,474 个完整帧扫下来，最后一帧是 160,397 tick，换算 2,506 秒，与界面显示的 41:46 一致，只差最后几 KB 收尾。

以前的封口逻辑只处理「截断点落在 spawn groups 帧里」这一种情况（那时帧流里已经有结束帧）。这次截断点落在播放数据中间、结束帧整块丢失，两道检查直接放弃，把坏文件原样交给 CS2，于是卡加载条。

现在的变化：

- 最后一个完整帧不是结束帧时，自动补一条合成的结束帧，再补空 spawn groups 与合成 fileinfo，头部两个偏移按实际位置写回。
- 顺手修了个隐藏偏差：健康 demo 的 fileinfo 里 `frames` 恒等于 `ticks + 1`（六份真实文件逐一验证），原代码填的是 `ticks`，差 1。
- 保留「保存点之前的帧必须帧帧完整、首尾相接」这道校验，中间有洞的文件不会硬封。

实测封口后帧流干净走到 EOF，尾部严格是 `Packet → Stop → spawnGroups → FileInfo`，两个偏移都指向正确帧；解析器重跑结果与原文件完全一致，零回归；CS2 实测能正常进入游戏。

#### 一键更新显示「更新成功」但版本号没变（已修）

上一版的一键更新有个致命 bug：如果你的程序放在带中文的路径下（比如 `E:\...\文案\CS2-Demo-Analyst`），更新脚本会跑到一个不存在的乱码目录里去，真实安装目录一个字节都没动，所以重启后看到的还是旧版本号。原因是更新脚本（.cmd）由程序按 UTF-8 写出，而 Windows 的 cmd 是按系统代码页（中文系统是 GBK）读脚本的，「文案」两个字被解成了「鏂囨」，路径就对不上了。

现在的变化：

- 所有路径改由环境变量传给更新脚本，不再写进脚本正文。环境变量走的是 Windows 原生 Unicode 通道，中文路径不会再变形。
- 更新脚本正文只剩纯 ASCII。
- 顺带修了另一个问题：以前脚本按「进程名」等程序退出，你要是同时开着两份程序，它会白等到超时（约 2 分钟）才动手；现在只等自己那一个进程退出。

注意：如果你现在用的是 1.0.4 或 1.0.5，这个 bug 就长在你正在跑的那份程序里，一键更新没法自己修自己，需要手动换一次：下载本页的 zip 覆盖到原目录（或者干脆解压到新目录），之后的一键更新才会正常。

#### 语音分割不产出音轨（已修）

之前点「语音分割」有些 demo 会一直提示「该 Demo 未提取到任何语音（MM 天梯 demo 不含语音）」，但那个提示是错的。真正的原因是内置的语音提取工具（csgove v3.1.6）解析不了较新的 CS2 demo，解析到一半就崩了，可是它崩完照样以「成功」的身份退出、一个文件也不产出，上层只看到「0 个音轨」，于是统一报成「这个 demo 没语音」。

现在的变化：

- 语音提取工具升级到 v3.1.7，能正常解析这些新 demo。
- 工具带版本标记，已经装过旧版的用户打开程序会自动换成新版，不用手动删文件。
- 拆出了「工具没跑通」和「demo 真没语音」两种情况的提示，不再混成一句话。真没语音的（比如 Valve 官方匹配 demo）会明确说没有音轨可用。

#### 语音识别不能用（已修）

之前默认推荐的 Groq 转写在国内被整段拒绝。实测结果是连不带 Key 的请求都返回 403、换浏览器标识和走代理也一样，响应体固定是一句 Forbidden —— 拦的是来源不是身份，所以那个推荐项放着就必然失败。

现在的变化：

- 默认引擎改成默认本地 Whisper，装好即用，不需要任何 Key，音频不出本机。
- 模型下载修好了：以前走 HuggingFace 官方地址，国内直连基本必然超时；现在优先走镜像并带上了镜像必须的下载参数，实测 74MB 的小样本 19 秒下完。镜像偶尔限流返回 429，程序会自动等几秒重试，不再一次失败就直接报错。
- 设置页的转写引擎简化成两档：本地 Whisper / 自定义 API。自定义 API 需要你自己填 API 地址、模型名、Key（任何兼容 OpenAI Whisper 规范的服务都行，比如硅基流动）。Groq 那个推荐项已经移除，老配置里如果还留着 Groq 地址，读到时会自动退回本地。
- 转写页不再显示那句容易被误解的时长提示。

#### AI 分析把击杀说反（已修）

之前问「这局都谁被 LIPSTICK 电了」，AI 会列出一长串「LIPSTICK 电击某人」，但那一局 LIPSTICK 只用电击枪杀过一个人，其它行都是把别人的击杀记到了他头上。查证下来 demo 解析数据本身完全正确（每一条击杀的攻击者、武器、受害者都对），错在把「攻击者 → 受害者」这种简写格式喂给模型时，弱模型会读反方向，还会把 Zeus x27 意译成「电击」；更麻烦的是一旦对话历史里出现过错答，它后面就会一直照着抄。

现在的变化：

- 能从数据直接算出来的问题（谁杀了几个、谁被谁杀、用某武器杀了几个人），不再交给模型，改由程序本地算出答案。答案永远和数据一致，也更快。
- 明细分两节列出：本人的击杀、本人的阵亡，时间点可以直接对着击杀流核对。
- 战术分析类问题（谁表现最好、关键转折在哪、为什么输）仍然交给模型回答。
- 顺带把交给模型的数据格式也改成了中文完整句式，并新增「玩家武器统计」一节作为事实基线，减少模型凭印象罗列。

### 更早版本带来的改动

解析库升级，较新的完美/5E demo 能正常解析；更新弹窗里可以点「一键更新」直接下载替换重启；半截的 demo（下载被打断、尾部少一截）能正常播放；半截 zip 能被扫到并解析；资料库目录行能直接打开文件夹；目录下拉默认回「全部目录」并记住上次的选择；删除 demo 时连带清理语音缓存。

### 一个必须知道的前提

Valve 官方匹配下载的 demo 不带语音数据，这类文件无法显示谁在说话——数据本来就不在文件里。带语音的是 FACEIT、5E、完美世界等第三方平台的 demo。

### 语音转写说明

- 默认本地 Whisper，完全离线，音频不出本机。
- 三个模型可选：基础（约 142MB，快但粗糙）、小（约 466MB，均衡，推荐）、中（约 1.5GB，精度更高但会把多句合并成一段，时间轴粒度变粗）。
- 如果嫌本地慢，可以在设置里填一个兼容 OpenAI Whisper 的 API 地址与 Key，走云端可秒级完成，代价是音频要上传给该服务商。
