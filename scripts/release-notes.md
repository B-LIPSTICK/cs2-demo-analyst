# CS2 Demo Analyst v1.0.4

本页资产已更新到 v1.0.4，之前下过旧包的请重新下载。

### 这一版改了什么

- **修好了「某个 demo 一直解析失败」**：部分较新的完美/5E demo 解析到一半会报错退出，界面上就是永远转不出数据。原因是底层 demo 解析库版本太旧，读不懂新版 demo 的实体编码。已升级到最新版解析库，这类 demo 现在能正常解析出回合、击杀、选手数据。
- 解析速度也有提升：同一局 demo 从三秒多降到两秒左右。

### 上一版已经带来的改动

更新弹窗里可以点「一键更新」直接下载替换重启；半截的 demo（下载被打断、尾部少一截）能正常播放；半截 zip 能被扫到并解析；资料库目录行能直接打开文件夹；目录下拉默认回「全部目录」并记住上次的选择；删除 demo 时连带清理语音缓存。

### 一个必须知道的前提

Valve 官方匹配下载的 demo 不带语音数据，这类文件无法显示谁在说话——数据本来就不在文件里。带语音的是 FACEIT、5E、完美世界等第三方平台的 demo。

### 下载

- 主推：`CS2-Demo-Analyst-1.0.4-win64-portable.zip`（本页 Assets 里），绿色版，解压即用
- 安装版：`CS2-Demo-Analyst-1.0.4-setup.exe`（同在本页 Assets 里），两者选一个装，别同时装两份
- 升级直接覆盖解压即可，配置在 `%APPDATA%\CS2 Demo Analyst`，不受影响
- Whisper 模型与 csgove 引擎首次使用按需下载，不含在 zip 内
