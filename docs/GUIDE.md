# 小白从 0 开始配置教程

> 目标读者：完全没用过本工具的新用户。跟着做，10 分钟跑通「导入 demo → 看分析 → 语音转写」。

---

## 第 0 步 · 你需要准备的东西

- 一个 CS2 demo 文件（后缀 `.dem`）
  - 在哪找？游戏内录制：控制台输入 `record 名字`，结束后在 Steam 的 `userdata/<你的ID>/730/remote/csgo/demos` 目录；
  - 或 FACEIT / 完美对战平台下载的对局回放（这些**通常带语音**，最适合体验转写）。
- 一台 Windows 电脑（桌面版）。

---

## 第 1 步 · 使用桌面版（Windows）

1. 下载 `CS2-Demo-Analyst-<version>-win64-portable.zip`，**解压**（不要直接双击 zip 里的 exe，先解压）。
2. 双击 `CS2 Demo Analyst.exe` 启动（免安装，杀毒软件若提示请放行）。
3. 首页点「添加目录」，选择你存放 demo 的文件夹 → 自动扫描解析。

---

## 第 2 步 · 看分析结果

1. 点任意 demo 卡片，进入详情页：
   - 顶部 HUD：地图名、**比分**（金色=T / 蓝色=CT）、时长、回合数
   - **回合时间轴**：金/蓝分段代表每回合胜负，菱形是击杀（红=爆头），点它可查看
   - **击杀记录**：武器、爆头标记（☠）、穿烟（SMK）
   - **选手数据表**：K/D/爆头率/MVP
2. 点时间轴上的回合/击杀，下方会联动显示该回合详情。

---

## 第 3 步 · 语音转写（核心功能）

> 前提：demo 卡片上有绿色「语音」标签（无此标签 = demo 里没有录制语音，跳过本步）。

1. 左侧导航进「转写」。
2. 顶部选择你的 demo → 点「**开始转写**」。

### 首次使用：配置转写引擎（二选一）

**选项 1：云端（最快，推荐）**

1. 进「设置」→「语音转写引擎」→ 选「云端 API」。
2. 点「**获取免费 Key**」→ 打开 Groq 官网注册（免费，无需绑卡）→ 复制 API Key。
3. 把 Key 粘贴到「API Key」输入框（其余保持默认）。
4. 回到转写页点「开始转写」→ **秒级出结果**。

**选项 2：本地（免费离线，隐私优先）**

1. 进「设置」→「引擎与模型」。
2. 依次点「下载」：语音提取器 csgove → 本地转写器 whisper-cli → 模型（推荐 small，466MB，中文效果好）。
3. 回到转写页点「开始转写」。CPU 转写一局约几分钟，可后台进行。

### 转写结果怎么用

- 每条转写：`时间 · 玩家 · 文本`，带引擎标签（本地/云端）与所属回合。
- 点任意一条 →（桌面版接好注入后）游戏内直接跳到该时刻。
- 可筛选玩家 / 回合、搜索关键词、导出 txt。
- 「文字聊天」选项卡可同时查看游戏内文字聊天。

---

## 第 4 步（可选）· 实况注入与游戏内悬浮层

### 让 CS2 可以被控制（一次性设置）

1. 进「设置」→「CS2 注入」→ 确认端口（默认 29000/30070）。
2. 桌面版：点「自动检测」找到 CS2 安装路径（找不到可手动填）。
3. **CS2 需要以 `-tools` 模式启动**（免费 Workshop Tools DLC）：
   - Steam 库 → CS2 → 右键属性 → 启动选项加 `-tools`；
   - 或一键完成：设置页「**安装 GSI 配置**」写入配置文件 +「**启动 CS2（-tools）**」直接拉起游戏。
4. 启动 CS2 并正常播放任意 demo → 回到本工具「实况」页 → 点「连接控制台」。

### 连接后你能做什么

- 「实况」页：暂停 / 播放 / 0.5x–4x 倍速 / 跳转回合 / 切换选手视角 / 直接输入 console 指令。
- 详情页 / 转写页：点击任意击杀、回合、转写行 → 游戏内**立即跳转**。
- 「游戏内悬浮层」（桌面版设置页开启）：CS2 画面角落显示说话者 HUD + 转写字幕 + 实时比分。

## 常见问题（FAQ）

**Q：转写出来是乱码/奇怪文字？**
A：多半是 demo 语音本身质量或引擎配置问题。先换「云端」引擎试；本地模型建议 small 起步。

**Q：demo 卡片没有语音标签？**
A：Valve 天梯（MM）demo 不录制语音；请用 FACEIT / 完美平台 / 自己录制的 demo。

**Q：转写很慢？**
A：本地 CPU 转写属正常；换云端引擎秒级，或本地用 N 卡 + CUDA 版（设置页模型处选择）。

**Q：实况页显示"未检测到 CS2"？**
A：确认 CS2 正在运行且以 `-tools` 启动。

**Q：demo 很大（几百 MB）拖进去没反应？**
A：耐心等进度条；浏览器解析 200MB 约 2–4 秒。

**Q：会把我数据传出去吗？**
A：解析/分析/语音提取全部在本地。云端转写仅把「该段音频」发送到你配置的 API（默认 Groq，可随时改/清空 Key）。
